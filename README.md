1. Problem Statement

To develop a Python-based Mad Libs Generator that creates funny and creative stories using user-provided words. The application provides a graphical interface to generate, save, view, and copy stories easily.

2. Objectives

- To generate creative and funny stories.
- To create an attractive GUI using Tkinter.
- To allow users to select different story templates.
- To save and view stories as text files.
- To understand basic Python programming concepts.

3. Algorithm

1. Start the application.
2. Display the graphical user interface.
3. Select a story template.
4. Enter five words: noun, verb, adjective, adverb, and place.
5. Validate the inputs.
6. Insert the words into the selected template.
7. Display the generated story.
8. Allow the user to save, view, or copy the story.
9. Stop the application when the user closes the window.

4. Python Concepts Used

- Tkinter: Creates the graphical user interface.
- Functions: Divide the program into smaller tasks.
- Dictionary: Stores story templates and random words.
- Conditional Statements: Check inputs and perform actions.
- Loops: Process input fields.
- Random Module: Selects random words.
- File Handling: Saves and opens story files.
- Exception Handling: Handles file errors.
- String Formatting: Inserts words into stories.
- DateTime Module: Creates unique filenames using date and time.

5. Features

- Attractive and colourful GUI.
- Four different story templates.
- Random word generation.
- Input validation.
- Generate funny stories instantly.
- Save stories in text files.
- Open previously saved stories.
- Copy stories to the clipboard.
- Clear input fields.
- Error and success messages.

6. Testing

- Test 1: Enter all valid words — story generates successfully.
- Test 2: Leave a field empty — warning message appears.
- Test 3: Click Surprise Me — random words are selected.
- Test 4: Click Clear — all input fields are cleared.
- Test 5: Save a generated story — text file is created.
- Test 6: Open a saved story — its contents appear in the story box.
- Test 7: Click Copy Story — story is copied to the clipboard.

Result: The application performs the main functions successfully when tested under normal conditions.

7. Future Scope

- Add more story templates and languages.
- Add text-to-speech to read stories aloud.
- Store multiple stories in a database.
- Add user accounts and personalised story collections.
- Develop a web or mobile version of the application.
